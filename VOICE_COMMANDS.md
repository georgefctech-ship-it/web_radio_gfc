# Comandos de Voz / Voice Commands

Este documento lista os comandos de voz suportados pelo Radio Player em Português e Inglês.
This document lists the voice commands supported by the Radio Player in Portuguese and English.

## Português (pt-BR)

| Ação | Comandos |
| --- | --- |
| Tocar Estação | "Toque [nome]", "Tocar [nome]" |
| Próxima Estação | "Próxima", "Proxima" |
| Estação Anterior | "Anterior", "Volta" |
| Mudo | "Mute", "Mudo", "Silêncio" |
| Iniciar Playback | "Play", "Tocar rádio" |
| Pausar Playback | "Pause", "Parar" |
| Aumentar Volume | "Volume alto", "Aumentar volume" |
| Abaixar Volume | "Volume baixo", "Abaixar volume" |
| Parar de Ouvir | "Parar de ouvir", "Desligar microfone" |
| Ajuda | "Ajuda", "Comandos" |

## English (en-US)

| Action | Commands |
| --- | --- |
| Play Station | "Play station [name]", "Tune to [name]" |
| Next Station | "Next" |
| Previous Station | "Previous", "Back" |
| Mute | "Mute", "Silent" |
| Start Playback | "Play", "Start" |
| Pause Playback | "Pause", "Stop" |
| Volume Up | "Volume up", "Louder" |
| Volume Down | "Volume down", "Quieter" |
| Stop Listening | "Stop listening", "Turn off microphone" |
| Help | "Help", "Commands" |
